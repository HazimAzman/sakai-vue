BIRTHDAY IMAGES DIRECTORY
==========================

Place birthday girl images in this directory.

Supported filenames (will be automatically detected):
- mimi.jpg
- mimi.png
- birthday-girl.jpg
- birthday-girl.png

The first matching file found will be displayed on the birthday page.

To add images:
1. Copy your image files to this directory
2. Rename them to one of the supported filenames above
3. Refresh the birthday page

Image recommendations:
- Recommended size: 400x300px or similar aspect ratio
- Formats: JPG, PNG
- File size: Keep under 2MB for best performance
